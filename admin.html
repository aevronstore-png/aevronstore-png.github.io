الدخول للوحة الإدارة

مرة وحدة بس: سوي مفتاح دخول من GitHub والصقيه هنا. المفتاح ينحفظ في متصفحك أنتِ فقط.

  1. افتحي صفحة إنشاء المفتاح وأنتِ داخلة بحساب aevronstore-png.
  2. في Token name اكتبي: AEVRON Admin، وفي Expiration اختاري المدة اللي تبغينها.
  3. في Repository access اختاري Only select repositories ثم aevronstore-png.github.io.
  4. في Permissions افتحي Repository permissions وخلي Contents على Read and write.
  5. اضغطي Generate token وانسخي المفتاح والصقيه تحت.
